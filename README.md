# Мессенджер — Android (APK) и Windows (EXE)

Мессенджер в стиле Telegram: **общий чат, группы, личные сообщения по ID, каталог
групп, поиск людей и звонки**. Один интерфейс на телефоне и на компьютере:
`main.py` — приложение, `server.py` — сервер на Python с текстовым протоколом.

## Версия для ПК (Windows) — Messenger.exe

1. **Готовый файл:** скачайте артефакт **messenger-windows-exe** из GitHub Actions
   (workflow *Build Windows EXE*) и запустите `Messenger.exe` двойным кликом.
   Python и Kivy внутри — один файл, около 30 МБ.
2. **Собрать самому:** двойной клик по `build_pc.bat` (нужен Python 3.10+;
   `build_pc.py` сам поставит PyInstaller) → `dist\Messenger.exe`.
3. **Запуск из исходников:** `messenger.bat` или `pip install kivy sounddevice`, затем `python messenger_pc.py`.

Настройки (сервер, имя, ID устройства) ПК-версия хранит в `chat_settings.json` рядом с EXE.
Горячие клавиши: **Esc** — назад к списку чатов, **Ctrl+F** — поиск людей,
**Ctrl+Enter** — меню чата, **правый клик** по шапке чата — меню.

Если сервер на этом же компьютере — в приложении укажите `127.0.0.1`, порт `55`.
Чтобы подключались телефоны, сервер запускается с `CHAT_BIND=0.0.0.0`.

## Что есть в приложении

| Раздел | Что делает |
|---|---|
| **Вход** | имя (гость, ID на устройство) или имя + логин + пароль (постоянный ID) |
| **Чаты** | список как в Telegram: общий чат, группы, личные диалоги, счётчик непрочитанных |
| **Общий чат** | все сообщения видны всем, история последних 50 сообщений |
| **Группы** | создание (`Группа +`), каталог с числом участников, вступление, участники по ID |
| **Личные сообщения** | диалог с человеком по его ID: аватар, «в сети», история переписки |
| **Поиск** | `Поиск` в шапке — найти человека на сервере по ID или имени, начать личный чат |
| **Звонки** | `Позвонить` в личном чате, полоса «Принять / Отклонить / Сброс» |
| **ID** | ваш ID виден в шапке «Чаты» и в «Меню» — нажмите на строку, чтобы скопировать |

Свои сообщения — в зелёных пузырях справа, чужие — в белых слева с именем и временем,
служебные события (вход/выход, звонки) — серыми плашками.

## Сборка APK через GitHub (без установки чего-либо)

1. Создайте **приватный или публичный репозиторий** на GitHub.
2. Загрузите в него **всё содержимое этой папки** (кнопка *Add file → Upload files*,
   либо `git init && git add . && git commit -m init && git remote add origin <url> && git push -u origin main`).
   Обязательно сохраните путь `.github/workflows/build-apk.yml` — именно так GitHub находит workflow.
3. Откройте вкладку **Actions** → workflow **Build APK** → **Run workflow** (или просто сделайте push).
4. Через 15–40 минут (первый раз дольше: скачиваются Android SDK + NDK) откройте завершённый запуск
   и скачайте артефакт **messenger-debug-apk** — внутри `messenger-1.0-arm64-v8a_armeabi-v7a-debug.apk`.
5. Перекиньте APK на телефон и установите (разрешите установку из неизвестных источников).

Если сборка упала — в том же запуске будет артефакт **build-log** с полным логом buildozer.
Workflow собирает на `ubuntu-24.04` (у `ubuntu-22.04` с 17.09.2026 идёт deprecation);
если захотите вернуться на 22.04 — поменяйте `runs-on`.

## Запуск сервера

```bash
python server.py                    # только этот компьютер (127.0.0.1:55)
CHAT_BIND=0.0.0.0 python server.py  # доступен с телефона и других машин
```

На Windows (PowerShell): `$env:CHAT_BIND="0.0.0.0"; python server.py`.
IP компьютера — команда `ipconfig` (раздел беспроводной сети, `IPv4-адрес`).

Что сервер хранит на диске:

| Путь | Что внутри |
|---|---|
| `chat_data/groups.json` | группы и их участники (переживают перезапуск) |
| `chat_data/accounts.json` | логины и пароли (только sha256-хеш с солью) |
| `chat_data/archive.json` | **вся переписка**: общий чат, группы, личные диалоги (до 500 сообщений на чат) |
| `logs/<дата>_общий.txt` | общий чат (текстовые логи по дням) |
| `logs/<дата>_группа_<название>.txt` | группы |
| `logs/<дата>_личные_<A>_и_<B>.txt` | личная переписка |

Эти папки в `.gitignore` — приватная переписка в репозиторий не попадает.

### Чаты не пропадают

- Список чатов (общий, группы, личные диалоги) хранится в настройках клиента
  (`chat_settings.json` рядом с EXE) **и** на сервере — после перезапуска программы
  или сервера все чаты остаются на месте.
- История любого чата подгружается с сервера при каждом открытии: сервер отдаёт
  последние 500 сообщений из `chat_data/archive.json` (файл сохраняется сразу
  после личного/группового сообщения и раз в 15 секунд для общего чата).
- Личное сообщение, отправленное человеку не в сети, сохраняется и попадёт к нему,
  когда он зайдёт в приложение (показано как непрочитанное).

## Как пользоваться

1. Запустите сервер на компьютере, телефон и компьютер — в одной Wi-Fi-сети.
2. В приложении укажите **IP сервера**, порт `55` и имя.
   Хотите постоянный ID — заполните логин и пароль (при первом входе аккаунт создаётся,
   при следующих — входите под тем же ID).
3. **Личный чат**: «Поиск» или «Личный чат» → введите имя/ID человека → нажмите на найденного.
   Свой ID покажите собеседнику (он в шапке «Чаты» и копируется нажатием).
4. **Группа**: кнопка «Группа +» → название. Добавить людей: откройте группу → «Меню» →
   «Участники / добавить по ID» (человек должен быть в сети).
5. **Звонок**: откройте личный чат → «Позвонить». На входящий звонок появится плашка
   «Принять / Отклонить». При первом звонке Android спросит разрешение на микрофон.

## Протокол (одна строка = одно сообщение, `\n` в конце)

Вход: `имя` или `имя|логин|пароль` (или `имя||ID_устройства` для гостя) → ответ `OK <имя> <ID>`.

Сервер → клиент: `MSG`, `HIST`, `USERS`, `JOIN`, `LEFT`, `NICK`, `INFO`, `ERR`,
`LIST` (каталог групп), `GMSG`/`GHIST` (группы), `DMSG`/`DHIST` (личные),
`GROUP+`/`GROUP-`/`GMEM`, `MEMBERS`, `SEARCH`, звонки `CALL`/`CALLRING`/`CALLA`/`CALLR`/`CALLB`/`VOICE`.

Клиент → сервер: сообщение, `PM <ID> <текст>`, `G <ID группы> <текст>`,
`/group <название>`, `G <ID> <текст>`, `/join`, `/gadd`, `/gleave`, `/search <ID или имя>`,
`DGHIST <ID>`, `MEMS <ID группы>`, `/list`, `/nick`, `/call`, `/answer`, `/decline`, `/hangup`,
`VOICE <base64>`, `/quit`. Команда `/help` печатает шпаргалку.

## Файлы

| Файл | Роль |
|---|---|
| `main.py` | приложение (общее для Android и ПК): экраны, список чатов, пузыри, поиск, группы, звонки |
| `messenger_pc.py` | запуск ПК-версии из исходников |
| `build_pc.py` / `build_pc.bat` | сборка `dist\Messenger.exe` (PyInstaller) |
| `messenger.bat` | запуск на ПК: EXE, если собран, иначе из исходников |
| `audio_android.py` | звук звонка через `AudioRecord`/`AudioTrack` (только Android) |
| `server.py` | сервер: чаты, группы, аккаунты/ID, поиск, сигнализация звонков |
| `buildozer.spec` | конфиг сборки APK: разрешения, API level, архитектуры |
| `Arial-Regular.ttf` | шрифт с кириллицей (штатный шрифт Kivy её не рисует) |
| `icon.png` | иконка приложения |
| `.github/workflows/build-apk.yml` | сборка APK на GitHub Actions |
| `.github/workflows/build-exe.yml` | сборка Windows-EXE на GitHub Actions |

Проверить интерфейс на компьютере: `pip install kivy sounddevice` и `python main.py`.
Локальная сборка APK — только Linux/WSL: `buildozer android debug` (см. `buildozer.spec`).
